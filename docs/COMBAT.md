# Núcleo de combate

Protótipo Python sem dependências para lógica de combate por turnos: vida, armadura, energia, ataques e recarga.

Executar: `python -m unittest discover -s tests -v`

Ainda não integrado ao motor 3D. Próximas etapas: animações, cooldown, colisões, IA de oponentes e interface de HUD.
